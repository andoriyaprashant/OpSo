## 📌 About the Project

**OpSo** (Open Source Programs) is a cross-platform Flutter application that serves as a centralized hub for discovering and exploring open-source contribution programs. Whether you're a student looking for your first open-source experience or a seasoned developer seeking new opportunities, OpSo brings all the information you need into one place.

### 🎯 Objectives

- **Centralize Information** — Aggregate details about 16+ open-source programs in a single app.
- **Simplify Discovery** — Help users find the right program based on their interests and skill level.
- **Provide Resources** — Offer program timelines, project listings, eligibility info, and learning paths.
- **AI-Powered Guidance** — Integrated chatbot to answer questions about open-source programs.

## 🚀 Getting Started

Follow these instructions to set up and run OpSo on your local machine.

### Prerequisites

Make sure you have the following installed:

- **Flutter SDK** (≥ 3.3.3) — [Installation guide](https://flutter.dev/docs/get-started/install)
- **Dart SDK** — Included with Flutter
- **Git** — [Download Git](https://git-scm.com/)
- **Code Editor** — [VS Code](https://code.visualstudio.com/), [Android Studio](https://developer.android.com/studio), or [IntelliJ IDEA](https://www.jetbrains.com/idea/)
- **Android Emulator / iOS Simulator** (optional) — For mobile testing

### Installation

1. **Fork** this repository by clicking the Fork button at the top right of the repo page.

2. **Clone** your forked repository:

   ```bash
   git clone https://github.com/<your-username>/OpSo.git
   ```

3. **Navigate** to the project directory:

   ```bash
   cd OpSo
   ```

4. **Install** dependencies:

   ```bash
   flutter pub get
   ```

### Environment Setup

The app requires a `.env` file in the project root for the AI Chatbot feature:

1. Create a `.env` file in the root directory:

   ```bash
   touch .env
   ```

2. Add your API key:

   ```env
   API_KEY=your_google_generative_ai_api_key_here
   ```

   > **Note:** You can obtain an API key from [Google AI Studio](https://aistudio.google.com/). The chatbot feature will not work without a valid key.

### Run the App

1. **Verify** your Flutter setup:

   ```bash
   flutter doctor
   ```

2. **Run** the app on a connected device or emulator:

   ```bash
   flutter run
   ```

   To target a specific platform:

   ```bash
   flutter run -d chrome     # Web
   flutter run -d windows    # Windows
   flutter run -d macos      # macOS
   flutter run -d linux      # Linux
   ```

## 💡 Usage

1. **Launch the app** — You'll be greeted with a splash screen followed by the landing page.
2. **Browse programs** — The home screen displays a grid of 16+ open-source programs with logos.
3. **Explore a program** — Tap any program card to view year-wise project listings.
4. **Search & filter** — Use the search bar and multi-select filters to narrow down projects.
5. **View details** — Tap a project to see detailed information, eligibility criteria, and links.
6. **Ask the AI Chatbot** — Tap the floating ChatBot button for AI-powered guidance.
7. **Bookmark programs** — Save your favorite programs for quick access from the drawer menu.
8. **Explore the Learning Path** — Access structured resources to start contributing to open source.
9. **Switch themes** — Toggle between dark and light mode from the drawer.

## 🤝 Contributing

We welcome contributions from everyone! Whether it's fixing a bug, adding a feature, improving documentation, or adding a new open-source program — every contribution counts.

### Quick Start

1. **Fork** the repository
2. **Create** a feature branch: `git checkout -b feature/your-feature-name`
3. **Make** your changes following the [Flutter style guide](https://flutter.dev/docs/development/tools/formatting)
4. **Test** your changes locally
5. **Commit** with a descriptive message: `git commit -m "Add feature XYZ"`
6. **Push** and create a Pull Request

### Ways to Contribute

- 🐛 **Report Bugs** — [Open an issue](https://github.com/andoriyaprashant/OpSo/issues) with detailed reproduction steps
- 💡 **Request Features** — Suggest new ideas via [GitHub Issues](https://github.com/andoriyaprashant/OpSo/issues)
- 📝 **Improve Documentation** — Fix typos, add examples, or clarify instructions
- 🌐 **Add a New Program** — Gather program info, create a screen, and add it to the home page

> 📖 For detailed guidelines, please read our [CONTRIBUTING.md](./CONTRIBUTING.md).
